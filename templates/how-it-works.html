Architecture & Pipeline

How AgriPredict AI Works

A transparent look into the end-to-end Machine Learning pipeline from field data to crop recommendation.

1
Input Ingestion

Step 1 — User Input

The user provides seven key field parameters through the web interface. These comprise four soil chemistry values (Nitrogen, Phosphorus, Potassium, and Soil pH) alongside three atmospheric parameters (regional ambient temperature, relative humidity, and rainfall precipitation).

2
Sanitization & Verification

Step 2 — Data Processing

The application validates the input values against physical, biological, and agronomic bounds (e.g. verifying pH is between 0 and 14, temperature is realistic, and no negative numbers or non-numeric tokens exist). Cleaned features are formatted into a structured Pandas DataFrame matching the model's fitted feature schema.

3
Ensemble Invocation

Step 3 — Machine Learning Model

The inputs are passed to the trained Random Forest Classifier loaded from model.pkl. This model was trained on the benchmark Crop_recommendation.csv dataset using Scikit-learn, consisting of an ensemble of 100 decision trees constructed with bootstrap aggregation.

4
Multi-Class Inference

Step 4 — Prediction

The model analyzes the seven parameters simultaneously across all 100 decision trees. Each tree casts an individual vote based on splitting thresholds learned from historical agricultural patterns, and the ensemble aggregates these votes into class probabilities across the 22 target crops.

5
Actionable Guidance

Step 5 — Crop Recommendation

The system displays the predicted crop along with confidence indicators, botanical classification, growth duration, water requirements, and an input summary table. In parallel, the query is safely logged to the local SQLite database for historical tracking.

🌾 Role of the 7 Agricultural Parameters

Nitrogen (N):

Crucial for leaf growth, chlorophyll formation, and leafy foliage vegetative vigor.

Phosphorus (P):

Stimulates early root development, seed germination, flowering, and energy transfer.

Potassium (K):

Regulates water stomatal conductance, disease resistance, and fruit/grain quality.

Temperature (°C):

Governs enzymatic rates, photosynthesis, dormancy break, and thermal time accumulation.

Humidity (%):

Affects evapotranspiration, pollen viability, and atmospheric moisture tension.

Soil pH:

Controls mineral solubility and micronutrient uptake efficiency across root membranes.

Rainfall (mm):

Direct seasonal water budget available to sustain vegetative transpiration cycles.
